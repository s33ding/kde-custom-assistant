Sidekick

An embeddable AI assistant that opens as a chat widget in any web page.

Click the 💬 button in the bottom-right corner to start chatting.

Embed in your own page

<script
  src="http://s33ding.com:58829/widget.js"
  data-api="http://s33ding.com:58829/api/chat"
  data-title="My Assistant"></script>

This demo runs with the mock provider by default. Set AI_PROVIDER=openai and OPENAI_API_KEY in .env for real responses.
